# Neural-Viz

Logiciel de visualisation de réseaux de neurones développé dans le cadre d'un TER à l'Université Paul Sabatier (IRIT).

## Objectif
Illustrer de façon claire et intelligible les transformations effectuées par un réseau de neurones (MLP) pour arriver à une prédiction ou une classification.

## Stack
- **Python 3.10+**
- **PyTorch** — construction et entraînement du réseau
- **Streamlit** — interface interactive
- **Matplotlib / Plotly** — visualisations

## Lancer l'application
```bash
pip install -r requirements.txt
streamlit run app.py
```
